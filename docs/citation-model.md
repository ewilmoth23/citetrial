# Citation model

Citations are structured application records, not decorations generated by a model.

1. Project-scoped retrieval returns a real source and chunk.
2. CiteTrail assigns a numbered evidence record and builds a marker such as `[Source 2, p. 8]` or
   `[Source 3, “Methodology”]` from stored location fields.
3. The model sees that marker plus an untrusted excerpt.
4. The validator accepts only source numbers present in the retrieval set. Invalid numbers are replaced
   with `[unsupported citation removed]` and a warning.
5. Used markers become `Citation` rows containing message, source, chunk, source text revision, excerpt,
   and location.

The model cannot authoritatively supply a title, author, publication, URL, page, heading, or line range.

## Corrections and historical citations

A later source correction never silently rewrites an existing citation. Superseded chunks become
historical and leave all current search indexes, but remain stored while citations or evidence records
refer to them. Each citation keeps the source revision that was searchable when the answer was created,
and the UI labels that revision. New answers retrieve only active chunks from the current revision.

This means an old citation remains an honest record of what CiteTrail used at that time, even if a later
review determines that the extraction needed correction. Deleting the source or project still removes
the entire lineage through the documented cascade.

## Quotations

Quoted spans in an answer are compared literally with retrieved excerpts. Unmatched model quotation marks
are removed and a warning is stored, preventing unverified text from remaining presented as a direct
quotation. Evidence links and timeline evidence are rejected unless their complete excerpt exists in the
chosen chunk or source document. This strict comparison favors traceability over fuzzy convenience;
punctuation or normalization differences must be corrected by selecting exact stored text.

## Unsupported citations

Any bracketed marker containing `Source` must match the supported numeric form and the current retrieval
set. An invalid marker is never silently presented as sourced: it is removed/flagged before the answer is
stored. A citation demonstrates source location, not truth, reliability, independence, or causal validity.
